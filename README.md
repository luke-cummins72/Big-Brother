# Big Brother — VR Escape Room

A single room VR escape puzzle built in Unity for Meta Quest. You wake up alone in a cabin deep in the woods with no memory of how you got there. The only way out is a locked door secured by a keypad — search the cabin, piece together the clues, and figure out the code to escape.

## Gameplay

You come to inside an isolated cabin in the woods, with no idea how you ended up there. The only way out is a single locked door secured by a keypad. Explore the cabin, examine objects, and piece together scattered clues to work out the correct code. Enter it on the door's keypad to escape.

- **Setting:** An isolated cabin in the woods
- **Objective:** Find the code and unlock the door
- **Style:** Single room, puzzle focused escape room — explore at your own pace, no timer or fail state
- **Interaction:** Full VR hand/controller interaction — pick up, examine, and interact with objects in the environment to uncover clues

## Platform & Requirements

- **Platform:** Meta Quest (standalone)
- **Engine:** Unity
- **Input:** Quest touch controllers

## Getting Started

### Play
1. Download/sideload the build APK onto your Meta Quest headset (or install via the Meta Quest store link, if published).
2. Put on your headset and launch **Big Brother** from your library/unknown sources.
3. Look around, interact with objects, and find the code to escape the room.

### Build from source
1. Clone the repo:
   ```bash
   git clone https://github.com/luke-cummins72/Big-Brother-VR.git
   ```
2. Open the project in Unity (see project's Unity version in `ProjectSettings/ProjectVersion.txt`).
3. Make sure the Android build module and Meta/Oculus XR plugin are installed via Unity Hub.
4. Switch platform to **Android** in Build Settings.
5. Connect your Quest headset (with Developer Mode enabled) or build an APK to sideload.
